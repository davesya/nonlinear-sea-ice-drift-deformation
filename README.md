# Nonlinear Sea-Ice Drift Deformation Analysis using Sentinel-1 SAR

Research internship project carried out at the **Space Applications Centre (SAC), 
Indian Space Research Organisation (ISRO), Ahmedabad**, under **Dr. Purvee Joshi, SE, EPSA, ISRO**.

## Overview

This project investigated nonlinear sea-ice drift deformation over the **Greenland Sea**
using dual-temporal **Sentinel-1 Synthetic Aperture Radar (SAR)** imagery.

The work involved extracting sea-ice drift fields and analysing their spatial deformation
through divergence, vorticity, and shear.

## Methodology

- Processed dual-temporal Sentinel-1 SAR imagery using **SNAP**
- Generated sea-ice drift vectors using **SIFT-based feature detection and feature matching**
- Applied **RANSAC-based outlier removal**
- Developed Python workflows using **NumPy, SciPy, and GeoPandas**
- Computed **divergence, vorticity, and shear** from spatially varying sea-ice velocity fields
- Compared **tile-wise and whole-domain deformation fields**
- Performed spatial visualization and analysis using **QGIS and ArcGIS**
